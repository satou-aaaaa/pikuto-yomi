# ピクトグラムよみ

駅や街で見るピクトグラム（案内用図記号）を見て、何を表すかを当てる1日5問のゲーム。赤い丸と斜線は「してはいけない」、黄色い三角は「気をつけて」、青い丸は「こうしてください」、緑の四角は「安全・避難」。色と形の決まりを知ると、はじめて見る記号でも見当がつきます。

- 遊ぶ: https://satou-aaaaa.github.io/pikuto-yomi/
- 今日の5問（記号よみ2・記号さがし2・なかまの色1）はだれでも同じで1日1回。上級（なかまの色3問・ヒントなし）、練習（何度でも）、とことん（何問続けて一度で解けるか）、集めた記号が並ぶ「記号帳」があります。
- 正解すると、記号の見かたと、どこで見るかのひとこと、国土交通省の一覧へのリンクが出ます。ヒントは「なかま」→「選び肢を2つにしぼる」の2段です。
- 文字の大きさは3段。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。禁止（丸と斜線）・注意（三角）・指示（丸）は、色が見分けにくくても形で分かります。火事の道具（赤い四角）と安全・避難（緑の四角）は形が同じなので、中の絵（消火器か、人や矢印か）で見分けます。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 記号の出どころと研究

- 記号の名前となかまは、JIS Z 8210「案内用図記号」の [国土交通省の一覧](https://www.mlit.go.jp/sogoseisaku/barrierfree/content/001727468.pdf) で確かめています（非常口・飲食禁止・ペット持ち込み禁止は同じ規格の付属書の記号）。色の意味は JIS Z 9103「安全色」（[国土交通省の資料](https://www.mlit.go.jp/common/001002202.pdf)）によります。
- 記号の絵は、名前と見かたをもとに、このゲームのために描いたものです。規格の図そのものではありません。本当の形は上の一覧で確かめられます。
- 思い出して答える練習は読み直すより記憶に残りやすいことが知られています（[Adesope ほか 2017](https://doi.org/10.3102/0034654316689306)）。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を使うため、ページを開くと Google に接続し、IP アドレスが届くことがあります（端末に文字を保存したあとでも、ブラウザが先に接続することがあります）。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（記号の名前と答えは入りません）。
